## Build the NIKA geospatial stack

NIKA's Developer Platform has three complementary tools. **OnlyMap JS** is the frontend layer for building interactive WebGL maps in the browser. **NIKA GeoEngine CLI** packages, tests, and versions geoprocessing workers with reproducible environments. **NIKA GeoEngine** runs those workers at scale on your own Kubernetes cluster.

## Choose where to start

<Steps>
  <Step title="Build an interactive map">
    Start with [OnlyMap JS](/onlymap/overview) when your goal is a browser-based map application, a visualisation, or an embeddable map experience.
  </Step>
  <Step title="Package a geoprocessing workflow">
    Start with [NIKA GeoEngine CLI](/nika-geoengine/overview), then follow [Installation & Setup](/guides/custom-geoprocess-deployment/installation) and [Your First Worker](/guides/custom-geoprocess-deployment/step-by-step).
  </Step>
  <Step title="Run workers at scale in your cluster">
    Deploy [NIKA GeoEngine](/geoengine/overview) on Kubernetes for GPU and high-memory pools, batch fan-out and role-based access, then pair it with OnlyMap JS to [build fullstack map processing](/geoengine/onlymap-fullstack).
  </Step>
  <Step title="Connect processing to GIS users">
    After publishing a worker, use the [QGIS](/nika-geoengine/qgis) or [ArcGIS Pro](/nika-geoengine/arcgis) integration so GIS users can run it without managing the local runtime themselves.
  </Step>
</Steps>

## Frontend and backend, clearly separated

OnlyMap JS owns the map interface: it renders data, responds to user interaction, and presents a geospatial experience in the browser. GeoEngine CLI and NIKA GeoEngine own processing: they give each worker its declared dependencies, compute environment, version history, tests, and deployment path.

Use any of them independently. Combine them when an application needs a rich map interface alongside repeatable, compute-intensive geoprocessing: build and test workers with GeoEngine CLI, run them at scale with NIKA GeoEngine, and show the results with OnlyMap JS.
